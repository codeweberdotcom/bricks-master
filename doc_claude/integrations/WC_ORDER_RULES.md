# Правила заказа (минимум, шаг, максимум количества)

Модуль родительской темы codeweber. Ограничивает количество товара в заказе: минимальное, кратное (шаг, например «по 5 штук») и максимальное. Заменяет плагины min/max quantity; правила на рубрики и общие настройки есть из коробки.

## Каскад правил

`товар → рубрика товара → общие настройки`

| Уровень | Где задаётся | Поля |
|---|---|---|
| Товар | вкладка WooCommerce «Order rules» («Правила заказа») в редактировании товара | режим: **Inherit** (наследовать, по умолчанию) / **Custom** (своё правило) / **No restrictions** (без ограничений); минимум, шаг, максимум |
| Рубрика | редактирование рубрики товаров (term meta) | минимум, шаг, максимум; 0 = не задано; подрубрики наследуют правило родителя, если у них нет своего |
| Общие | Redux: Theme Settings → Woocommerce → Order rules | включить модуль; минимум, шаг, максимум по умолчанию; показывать ли текст на странице товара; свои тексты (на странице и ошибок) |

Правила выбора:

- Режим товара `none` отключает все ограничения для товара; `custom` использует только поля товара; `inherit` идёт дальше по каскаду.
- Для товара в нескольких рубриках у каждой рубрики ищется ближайшая (она сама или предок) с правилом; побеждает **самая глубокая**; при равной глубине берутся **большие значения** каждого поля.
- Общие настройки действуют только для товаров, у которых нет ни своего правила, ни правила рубрики.
- Переключатель «Enable order rules» отключает модуль целиком (все уровни).
- Значения нормализуются: минимум ≥ 1 и кратен шагу (округляется вверх), максимум кратен шагу (вниз) и не меньше минимума. Шаг 0 или 1 = любое количество.
- Вариации используют правило родительского товара.

## Что делает на сайте

- Страница товара: поле количества с минимумом, шагом (`data-step`), максимумом; **стартовое значение = минимум** (округлённое до кратного), поэтому итог EPO сразу показывается за минимальную партию; под формой текст «Минимальный заказ: 5 шт. Продаётся кратно 5.».
- Кнопки «+/−» шагают по шагу; введённое вручную значение округляется вверх до допустимого (`order-rules.js`, подключается на страницах товара и корзины; поля без шага остаются на родительском обработчике).
- Серверные проверки (классические шаблоны корзины и оформления): добавление в корзину (проверяется количество, добавляемое сейчас; каждая строка корзины сама по себе), изменение количества в корзине (0 = удаление строки, разрешено), действие `woocommerce_check_cart_items` (корзина и оформление заявки).
- Сообщения на русском; в Redux можно задать свои тексты с подстановками `{product}`, `{value}`.

## Файлы

```

  order-rules.php        загрузчик
  rules-resolver.php     codeweber_order_rules_get(), каскад, нормализация, check/snap
  rules-admin.php        вкладка товара, поля рубрики, сохранение (nonce, права, absint)
  rules-frontend.php     аргументы поля количества, стартовое значение, текст на странице, подключение JS
  rules-validate.php     проверки добавления/изменения/корзины, сообщения
  order-rules.js         «+/−» с шагом, округление
  order-rules-admin.js   показ полей «своего правила»
woocommerce/global/quantity-input.php   шаблон поля количества (+ data-step)
redux-framework/sample/sections/codeweber/woocommerce.php   раздел Redux «Order rules» (подраздел Woocommerce)
```

Подключение: `functions/woocommerce/init.php` → `require_once $_woo_dir . 'order-rules/order-rules.php'` (только при активном WooCommerce).

## Ключи и API

| Что | Ключ |
|---|---|
| Мета товара | `_cw_qty_mode` (`inherit` / `custom` / `none`), `_cw_min_qty`, `_cw_qty_step`, `_cw_max_qty` |
| Term meta рубрики (`product_cat`) | `_cw_min_qty`, `_cw_qty_step`, `_cw_max_qty` |
| Опции Redux (`redux_demo`) | `cw_qty_enabled`, `cw_qty_min`, `cw_qty_step`, `cw_qty_max`, `cw_qty_show_notice`, `cw_qty_notice_text`, `cw_qty_msg_min`, `cw_qty_msg_step`, `cw_qty_msg_max` |

```php
$rules = codeweber_order_rules_get( $product ); // WC_Product или ID
// [ 'min' => 5, 'step' => 5, 'max' => 0, 'active' => true, 'source' => 'category', 'source_id' => 123 ]
```

`source`: `product`, `product-none`, `category`, `global`, `none`, `disabled`.

Фильтр `codeweber_order_rules_resolved( $rules, $product )` позволяет другим модулям менять итоговое правило (например, минимум из расчёта конфигуратора или правило по роли пользователя).

## Миграция с плагина Min Max Quantities (PluginEver)

Плагин хранит правила в `_wcmmq_min_qty`, `_wcmmq_step`, `_wcmmq_max_qty`, переключатели `_wcmmq_enable` (своё правило) и `_wcmmq_disable` (исключить). Для переноса: если `_wcmmq_enable = yes` и `_wcmmq_disable` не `yes`, записать `_cw_qty_mode = custom` и значения в `_cw_min_qty`, `_cw_qty_step`, `_cw_max_qty`; затем отключить плагин (иначе правила применятся дважды).

## Ограничения

- Корзина и оформление на классических шаблонах (Store API / блоки WooCommerce не покрыты).
- Минимум динамический (из расчёта EPO, `R_qlm`) в модуль пока не входит: точка расширения — фильтр `codeweber_order_rules_resolved`.
- Переводы: `languages/codeweber.pot`, `languages/ru_RU.po` (после правок `wp i18n make-mo languages/ru_RU.po` и `wp i18n make-php languages/ru_RU.po`).
